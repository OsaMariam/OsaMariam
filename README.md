## Projects

**[SOC Level 2: Root Cause Analysis of a Malware Beaconing Incident](https://github.com/OsaMariam/soc-l2-root-cause-beaconing-investigation)**
Took an escalated beaconing alert and traced it back three days and three processes to a fake PDF a contractor downloaded, then built a detection rule to close the gap that let it through.

**[SOC Simulator: Alert Triage Series](https://github.com/OsaMariam/soc-simulator-alert-triage)**
Three alerts worked end to end from a live queue. Two of them are near identical attacks with opposite outcomes, one blocked and one allowed, which is where the real judgement sits.

**[VPN Log Investigation with ELK](https://github.com/OsaMariam/elk-vpn-bruteforce-investigation)**
274 failed VPN logins in one hour, traced through to three successful ones and a confirmed account compromise with scripted persistence.

**[EDR Alert Triage Across a Corporate Fleet](https://github.com/OsaMariam/edr-alert-triage-endpoint-detections)**
Triaging live endpoint detections across 55 hosts using only endpoint telemetry: process chains, command lines, IOCs and ATT&CK mappings.

**[Splunk Log Ingestion and VPN Log Analysis](https://github.com/OsaMariam/splunk-vpn-log-analysis)**
Onboarding a raw JSON log source into Splunk Enterprise properly, then querying it with SPL to answer investigation questions.

**[Building a Threat Intelligence SOAR Workflow](https://github.com/OsaMariam/soar-threat-intel-workflow)**
Configuring a SOAR workflow and deciding which steps should run automatically and which need a human analyst, with the reasoning for each switch.
